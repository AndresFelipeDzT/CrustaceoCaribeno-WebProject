# 🦀 Crustáceo Caribeño — Landing Page (Sprint 1)

Bienvenido al repositorio oficial del proyecto **Crustáceo Caribeño**, una plataforma web gastronómica enfocada en comida de mar y sabores auténticos del Caribe.

Este repositorio corresponde a la entrega del **Sprint 1**, centrada exclusivamente en el desarrollo, maquetación y diseño responsivo de la **Landing Page (`home.html`)**, aplicando buenas prácticas de desarrollo web, semántica HTML5, modularidad en CSS3 y diseño fiel a los prototipos de Figma.

## 🌊 Visión General

**Crustáceo Caribeño** busca brindar a los usuarios una experiencia digital cálida, elegante e inmersiva que evoque la frescura del mar y la riqueza de la cocina caribeña.


## 📁 Estructura del Proyecto

```text
Sprint1/
│
├── html/
│   └── home.html             # Landing Page principal del restaurante
│
├── css/
│   ├── general.css           # Tokens de diseño, tipografías, colores base y reset
│   └── home.css              # Estilos modulares específicos para la Landing Page
│
├── js/
│   └── home.js               # Lógica e interactividad de la página de inicio (scroll suave, etc.)
│
└── images/                   # Imagenes usadas en la página web

```
