Arquitectura RxJS del Taller:
  • Buscador Reactivo: Integra debounceTime y distinctUntilChanged para filtrar pulsaciones rápidas y descartar consultas consecutivas repetidas.
  • Sin routing: Todo el flujo corre sobre esta pantalla inicial única con componentes declarativos.
  • Componentes hijos desacoplados: <app-user-card> y <app-post-list> reciben datos limpios vía @Input.
  • Operadores utilizados: switchMap (para alternar y cancelar peticiones previas), concatMap (para encadenar secuencialmente Usuario → Posts → Comentarios), map (para vincular datos en memoria), y catchError para el manejo robusto de excepciones.
