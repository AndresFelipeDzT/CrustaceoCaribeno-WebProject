¿Cómo funciona la programación reactiva aquí?

  1. Se lanza http.get('/users?username=' + username) que retorna un Observable.
  2. Dentro de .pipe(mergeMap(...)), una vez recibido el usuario, extraemos su usuario.id.
  3. Se retorna el segundo observable: http.get('/posts?userId=' + usuario.id).
  4. El .subscribe() final captura las publicaciones únicamente cuando ambas peticiones se completaron en orden, evitando datos nulos.
